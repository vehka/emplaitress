# emplaitress
leeloo dallas multiplaits

This is a Norns mod that gives you access with `nb` to four copies of the Mutable Instruments Plaits code. 

`;install https://github.com/sixolet/emplaitress`

Turn on the mod

Then restart. On norns, the mod downloads the Mutable Instruments UGens the
first time it loads and shows an installer screen; press K3 on the "restart
needed" screen to restart once more. Other platforms (desktop) need
[mi-UGens](https://github.com/v7b1/mi-UGens) built and installed into
`~/.local/share/SuperCollider/Extensions`; until then the mod loads quietly and
the voices stay silent.
